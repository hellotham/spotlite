Provided strategic consulting services:

- Developed a financial model and engaged Finance stakeholders for a business case for a multi-year investment programme for a suite of Enterprise applications.
- Led and developed a Proof of Concept of a native iOS app written in Swift authenticating via Azure AD and accessing Outlook calendar and AD details via Microsoft Graph API.
- Led and developed a Proof of Concept demonstrating a JavaScript web front end embedded in a ServiceNow portal accessing a backend OData SAP service.
- Facilitated and led a vendor-sponsored Proof of Concept to develop a Chatbot servicing leave requests.
- Developed a set of management KPI dashboards using Tableau and Custom SQL.
- Conducted text analysis machine learning (using fast.ai and AWS SageMaker) to predict correct resolver group for IT incidents.
- Mentored senior employees and participated in Women in IT Leadership group.
